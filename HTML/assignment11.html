BSIT Dynamic Course Advisor

This advising tool uses an external JSON file to dynamically create the course interface for the Bachelor of Science in Information Technology program. The advisor starts blank so you can enter everything manually. The optional Load Advisor Example button only fills a sample set of lower-level prerequisite checkboxes; it does not create semesters or add program courses.

The advisor demonstrates AND prerequisites, OR prerequisites, corequisites, dynamically generated interface elements, drag and drop, and JavaScript event handling.

Step 1 - Courses Already Completed

Select the prerequisite and lower-level courses you have completed. In "choose one" groups, selecting one option disables the other alternatives because only one is required for this advisor.

Step 2 - Program Courses

These cards are created dynamically from the JSON data and are used to review each program course, its current status, and its requirements. Mark a program course complete after you have taken it, or select Details for prerequisites, semester availability, notes, and its catalog link.

Step 3 - Build a Degree Plan

Add each semester and year you want to use for your plan manually. The active planning semester is only a visual planning focus; it no longer controls which courses appear below. As soon as a prerequisite is completed or planned, its dependent course can appear in Courses You Can Take. If you do not yet have a valid semester for that course, add one and then drag the course into it. Courses already in the plan can also be dragged to another semester as long as the new placement keeps the prerequisite sequence valid. While a course is being dragged, any semester that is not a valid destination is highlighted red. This includes the semester containing a planned prerequisite, every semester before that prerequisite, and any semester in which the course is not offered. Nothing is preloaded or automatically added.

Courses You Can Take

A course appears here as soon as its prerequisites have been completed or placed somewhere in your degree plan. It does not need to match an existing planning semester yet. The Offered line shows which semesters normally offer the course. When you click and hold a course, a visible floating copy follows your cursor until you drop it, while red highlighting shows invalid destinations.

Assignment Modifications and Features

  1. Used the Daytona State College 2026-2027 BSIT degree program instead of the example advisor.
  2. Created the course and prerequisite structure in an external JSON file.
  3. Added recursive AND and OR prerequisite checking.
  4. Added corequisite checking for courses that allow a course to be taken in the same semester.
  5. Added mutually exclusive "choose one" lower-level requirements.
  6. Added semester-aware course availability for Fall, Spring, and Summer.
  7. Added dynamically generated course cards, status badges, course information, and catalog links.
  8. Added a customizable multi-year degree planner with user-selected semesters and years.
  9. Added prerequisite sequencing so courses planned in earlier semesters unlock dependent courses in later semesters.
  10. Added HTML5 drag and drop from the dynamically generated eligible-course list into planned semesters.
  11. Added drag-and-drop rescheduling of planned courses with prerequisite-sequence validation and a single red invalid-destination highlight for prerequisite semesters, earlier semesters, and semesters where the course is not offered.
  12. The advisor starts blank on every page load so completed courses, semesters, years, and planned courses are all entered manually.
