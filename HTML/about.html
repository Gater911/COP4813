About This Website

This website was created for my COP4813 Web Application Programming course. It is a central location for the assignments I complete throughout the semester.

The site is also intended to function as a small professional portfolio. As the course progresses, I can add new pages and projects that demonstrate my ability to build clear, organized, responsive, and accessible web experiences.

Skills Demonstrated

The current website demonstrates HTML5 structure, CSS styling, navigation, images, responsive design, accessibility practices, descriptive metadata, version control with Git and GitHub, and publishing with GitHub Pages.

Course Goal

My goal is to continue expanding this website as I learn additional client-side and server-side web programming concepts in COP4813.
