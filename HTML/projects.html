Active Web Development Project

Reefside Reptiles

Reefside Reptiles is a website I developed and maintain for my reptile breeding business. The project has given me practical experience working on both the public-facing front end and the administrative back end of a live website.

Front-End Development

  • Designed and organized the public-facing pages, navigation, and site layout.
  • Created animal listings and individual animal pages for visitors to browse.
  • Added clear animal status labels such as For Sale, Sold, NFS, and On Hold.
  • Built homepage sections for featured snakes and holdbacks, with each animal linking to its individual page.
  • Worked on responsive presentation, usability, and keeping information easy for visitors to understand.

Back-End and Administration

  • Developed an administrative area for managing the animals and information displayed on the website.
  • Added controls for choosing which animals appear in the featured and holdback sections of the homepage.
  • Created tools for updating animal availability and other information without manually rebuilding the public pages.
  • Added page update tracking so visitors can see when an animal's information was last updated.
  • Integrated an API-based contact system that allows visitors to send general questions or inquire about a specific animal directly through the website.
  • Worked on improving the security of the administrative login, including multi-factor authentication using authenticator codes.

This project combines front-end design with back-end management so the public website can stay current while the site's content is managed through a separate administrative interface.
